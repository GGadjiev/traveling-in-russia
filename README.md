# Traveling to Russia

Учебный проект адаптивного лендинга о путешествиях по России. Это мой пятый проект, на котором я впервые использую JavaScript и создаю двуязычную версию страницы.

## Цель проекта
Добавить интерактивность на JavaScript — реализовать слайдер галереи с навигацией, и сделать двуязычную версию сайта (RU/EN).

## Технологии
* **HTML5**: семантическая разметка, `loading="lazy"` для изображений, две языковые версии страницы (RU/EN).
* **SCSS**: модульная структура (partials по секциям и компонентам), CSS-переменные через `:root`, `@import`, `@include`, медиамиксины для `@media`.
* **CSS3**: CSS Grid и Flexbox, `calc()` для контейнеров, `clamp()` / `vw`-единицы через кастомные миксины `fluid-font`, `fluid-width`, `fluid-height`, `opacity`, `scale`, `transform`.
* **JavaScript (vanilla)**: интерактивный слайдер галереи с навигацией, работа с DOM (`querySelector`, `classList`, `addEventListener`).
* **Шрифт**: Inter (Regular, Bold, Black) — локальные `.ttf`-файлы.

## Чему я научился
* Писать простой JavaScript для интерактивности: слайдер с переключением классов.
* Делать двуязычную версию страницы.
* Продолжил работать с модульной SCSS-архитектурой и адаптивной типографикой.

## Текущее состояние
* **Адаптивность**: страница адаптирована для мобильных, планшетов и десктопов.
* **JavaScript**: реализован слайдер галереи.
